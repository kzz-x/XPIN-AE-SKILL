适用：用户希望把现有 AEP / 已完成镜头 / 一组同风格组件整理成可长期复用的人机共用模板。

## P0｜先保护原件
模板化不是“在原工程里整理”。

正式写入前必须：
1. 确认源 AEP / 源素材位置；
2. 建立可靠恢复点；
3. 创建独立模板化工作副本；
4. 后续重命名、整理、拆组件、删冗余、Relink、Collect 等只作用于副本；
5. 不移动、不覆盖、不删除用户本地原 AEP 与原素材；
6. 工具不能可靠复制 / 备份时，不进行高风险结构写入。

## 执行目标
优先把资产整理成：
`视觉系统包 → 完整套装 → 场景模板 / 独立组件 → 公共素材 / 依赖 / 预览 / 说明`

完整套装是唯一设计母体。独立组件和场景从完整套装派生，不分别长期维护。

## AE 内部硬规则
- 模板型 AEP 项目面板优先：`00_开始这里 / 01_主输出 / 02_编辑区 / 03_替换槽位 / 04_功能模块 / 05_素材 / 90_参考 / 99_核心`。
- **控制器属于合成内部**：每个主要可编辑合成时间线最上方放自己的控制 Null；不要额外用项目面板“控制文件夹”替代这一入口。
- 高频替换内容 SLOT 化。
- 底层 Rig / 表达式 / 材质等进入核心区域，正常调用默认不动。
- 人类可见命名中文优先。

## 依赖
必须盘点插件、字体、脚本、预设、LUT、Codec、3D 模型 / HDRI / 贴图、外部媒体 / 数据、Adobe 版本、Dynamic Link / Media Encoder、GPU 等可能脱机项。

可合法分发的依赖可随包提供；商业 / 受限依赖只提供版本、官方来源、安装说明和缺失影响。

缺依赖时先提醒，不得静默替换。

## 发布门禁
模板完成后先进入待审核，不自动覆盖旧正式模板。
正式发布版只读；生产使用必须复制到工作区。
已有项目中的模板副本不自动随母版升级。

## 完成回报
保持简短，至少说明：
1. 本次操作的是哪个副本，源工程是否保持未改；
2. 完整套装 / 场景 / 独立组件整理结果；
3. 依赖与缺失项；
4. 主要 SLOT / CTRL 使用入口；
5. 还未达到发布标准的项目。
