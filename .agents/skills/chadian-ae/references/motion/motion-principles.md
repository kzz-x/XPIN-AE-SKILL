# Motion｜Principles

> 仅在明显动画设计 / 编排任务中加载。目的不是增加关键帧数量，而是让动作有意图、有重量、有节奏，并能被后续人工调整。

## 1｜先设计运动，再打关键帧

每个主要动作先回答：
1. **对象是什么**：UI / 机械 / 文字 / 数据 / Camera / 软性图形？
2. **为什么动**：进入、强调、解释关系、切换状态、反馈、转场，还是引导视线？
3. **受什么约束**：重量、连接关系、空间路径、节奏、镜头连续性、信息可读性？

不要从“Position + Scale + Easy Ease”开始。

## 2｜统一动作骨架

默认从以下结构思考：

**准备 → 加速 → 主运动 → 减速 → 超越/跟随 → 稳定**

这 6 段是设计检查框架，不是强制模板。没有必要的阶段应删除。

- **准备 / Anticipation**：主动作前的反向或蓄力提示；只在能增强可读性、重量或意图时使用。
- **加速 / Acceleration**：从静止建立方向和力，不要机械地从第一帧就匀速。
- **主运动 / Main Motion**：承担主要位移、旋转、缩放、展开或状态变化。
- **减速 / Deceleration**：接近目标时释放速度，避免突然刹停。
- **超越 / Follow Through**：Overshoot、拖尾、附属部件延迟、惯性延续；是否存在取决于对象属性。
- **稳定 / Settle**：回到可读、可停留的最终状态。稳定本身也是动作的一部分。

## 3｜Timing 与 Spacing

- **Timing 决定动作花多久；Spacing 决定每一帧走多远。** 两者必须同时设计。
- 同样 12 帧的动作，可以通过不同 spacing 表现轻、重、硬、软、快、慢。
- Ease 不是风格本身；Ease 只是 spacing 的一种实现。
- 关键动作优先在 Graph Editor / 速度关系层面判断，不只看关键帧数量。
- 进入快、稳定慢；强调动作可短促；信息展示必须给观众读完的 Hold。

## 4｜核心运动原则的执行规则

- **Ease**：根据对象与意图决定曲线，不默认 Easy Ease。
- **Anticipation**：用于蓄力、点击反馈、机械启动、强强调；轻量 UI 和数据变化通常不需要明显 anticipation。
- **Inertia / Weight**：越重，速度变化越慢、惯性越明显、反弹通常越克制；越轻，响应越快。
- **Overshoot**：必须有理由。精密机械 / 数据通常极小或没有；软性图形可以明显。
- **Follow Through**：主体先到，附属元素、装饰、拖尾或次级模块稍后完成。
- **Overlapping Action**：多个相关部件不必同帧开始/结束；通过重叠形成连续流动。
- **Arc**：真实空间移动、指针、手势、机械摆动优先考虑弧线；UI 对齐运动可保持直线。
- **Squash & Stretch**：只用于适合形变的对象或强调，不把刚性物体做成果冻。
- **Secondary Action**：服务主动作，不抢视觉层级。
- **Staging**：同一时刻只让观众处理有限的主要变化；复杂镜头要安排主次。
- **Rhythm**：使用快 / 慢 / 停、密 / 疏、同步 / 错帧形成段落，而不是整段持续等速运动。
- **Contrast**：重要动作与普通动作在幅度、速度、曲线或停顿上形成对比。
- **Line of Action**：运动方向应服务视觉流线，避免无意义的方向互相抵消。
- **Continuity**：前后动作在速度、方向、空间关系上有承接；Camera 尤其不能无理由瞬间改向或急停。

## 5｜节奏单位

复杂镜头至少识别：
- **Primary Beat**：观众应该首先注意的主动作。
- **Secondary Beat**：补充信息、跟随、状态变化。
- **Rest Beat**：短暂停留，让信息被看清，也给下一动作建立对比。

不要让所有对象同时开始、同时结束、全程都在动。

## 6｜禁止的通用模板化

出现以下情况应主动重设计：
- 所有对象都是 Easy Ease；
- 所有对象都是 `Opacity 0→100 + Scale 80→100`；
- 所有对象都有同样幅度 Overshoot；
- 轻 UI、重机械、文字、Camera 使用相同曲线；
- 为了“更有动画感”增加无意义 bounce / shake / rotation；
- 只堆关键帧，不设计 Hold、Settle 和动作主次。

## 7｜完成判断

一个动作成立，至少能解释：
- 为什么这样开始；
- 为什么这样加速 / 减速；
- 为什么有或没有 Overshoot / Follow Through；
- 为什么此时结束并稳定；
- 它与前后动作、镜头和信息阅读的关系是什么。
