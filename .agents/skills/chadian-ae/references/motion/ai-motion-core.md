# AI 动效开发核心经验

> 用于复杂三维科普、结构动画、宏微观连续转场、互动 3D / Vibemotion 与 AE 复杂 Motion 的轻量指导。
> 只保留跨项目反复成立的高价值经验；目标是减少返工，不限制创作发挥。

## 维护原则

- **压缩式更新，不做追加式堆积。** 新经验优先合并、替换、压缩已有规则。
- **项目细节不进入本文件。** 参数、单次 bug、案例过程留在项目复盘。
- **只规定关键判断，不规定唯一实现。** 让 Agent 保留技术选择与创作空间。

## 核心原则

1. **结构先于视觉**：先确认层级、连接、尺度、数据/能量路径与知识逻辑，再做材质、灯光和装饰。
2. **空间运动先于透明度**：优先推进、剖开、重排、翻转、拆解、聚合、尺度变化；淡入淡出只用于必要收尾。
3. **先设计路径，再调缓动**：穿模、跳变、突兀先查旋转中心、扫掠空间、相机通道和安全距离；Graph/Easing 只优化节奏。
4. **动画共享统一时间状态**：同一时间点应得到一致的 Camera、模型、特效和标注状态；暂停、跳转、拖动、反向和录制结果应可复现。
5. **宏观与微观保持对象连续性**：尽量追踪同一对象、区域或结构关系，不靠整组替换 + 透明度掩盖断裂。
6. **材质质感不能依赖后期掩盖**：几何、灯光、反射、材质和接触关系先成立，再加 Glow/Bloom、DOF 等。
7. **标注和特效也是动画的一部分**：有明确出入场并跟随真实对象；路径、强度、脉冲与模型、Camera 同步。
8. **模板优先数据驱动和可复用**：稳定身份、清晰模块边界、共享状态；避免为单镜头把结构和参数写死。
9. **先做代表样片，再扩展功能**：先跑通一个代表镜头，再批量增加预设、控件和技术类型。
10. **验收看全过程**：检查关键中段、切换、暂停、反向、拖时间线、循环、隐藏恢复、标注和最终导出，不只看最好看的截图。

## 推荐顺序

**结构关系 → 代表镜头 → 连续转场 → 安全运动路径 → 统一时间状态 → 标注/特效 → 材质灯光 → 控件 → 录制/导出 → 回归测试 → 扩展**
