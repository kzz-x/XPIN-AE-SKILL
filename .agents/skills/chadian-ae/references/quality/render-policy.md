# Quality｜Render Policy

工程完成 ≠ 渲染授权。

## 默认
不启动：
- 完整 work area Render
- aerender 全片
- AE Render Queue 全片
- Media Encoder 全片
- 静默后台完整视频渲染

用户会在 AE 前台预览。

## 默认验收
需要检查视觉时：
- 输出 4–6 张关键帧 PNG
- 主合成原始分辨率
- 时间点根据动画结构选择，不机械平均
- 每张说明检查目的

## 完整渲染授权
只有用户明确说：
- 渲染成片
- 导出视频
- 给最终完整预览
或明确等价指令。

启动前确认：
- 主合成
- 时间范围
- 分辨率
- FPS
- 编码 / 格式
- 输出路径
- 音频
