# Workflow｜Hybrid MCP + JSX

推荐用于：
- 已打开真实工程 + 大量批量修改
- MCP 能定位但逐层写太慢
- JSX 能批量做但需要真实状态验证

标准循环：

1. MCP 读取真实 Project / Comp / Layer / Controls。
2. 明确修改范围和稳定 ID。
3. 生成最小 JSX / batch，只负责确定性修改。
4. 执行。
5. MCP 重新读取结果。
6. 必要时局部 Patch。
7. 输出关键帧验收，不自动完整渲染。

MCP 负责“看清楚和确认”，JSX 负责“高效、确定地批量做”。

禁止：
- 读取后仍按假定结构生成整套新工程；
- 因为 JSX 快就覆盖用户手工修改；
- 因为 MCP 能点就退化成低质量堆层。
