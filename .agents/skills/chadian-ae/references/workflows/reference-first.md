# Reference First｜AE 参考驱动制作

用于“新视觉 / 新动画 / 复杂结构 / 真实性重要”的 AE 任务。普通改字、改色、改尺寸、已有动画的小 Patch 不需要为了流程额外搜索。

核心原则：

**先确定参考依据，再决定 AE 怎么做。容易脚本化，不等于应该凭空设计。**

## 1｜Reference Preflight

动手前判断是否需要：

- **Identity / Structure**：真实产品、零件、设备、UI、Logo、机械结构；
- **Visual**：构图、排版、材质、灯光、HUD / 信息层；
- **Motion**：视频、GIF、Lottie、成熟 AE / UI motion 案例；
- **Physical / Biological Motion**：人、手、动物、液体、金属、机械、碰撞、装配等真实运动；
- **Reusable Asset**：PNG / SVG / Lottie / Footage / 3D / Template。

静帧只能约束视觉，不能证明运动。Motion 是重点时，应尽量有视频 / GIF / Lottie / 成熟动画参考。

## 2｜强制触发

以下情况默认先找 / 读取参考，或明确使用用户已有参考：

- 产品 / 品牌 / 设备 / 零件外观需要准确；
- 复杂机械结构、装配关系或物理运动；
- 人物、手、动物等类生物动作；
- Camera / 产品广告 / UI / HUD 需要模仿成熟运动语言；
- 用户反馈“动作不自然 / 太模板 / 一眼 AI / 结构画错”；
- 存在直接复用成熟素材、Lottie、SVG、视频、模板的可能。

如果当前环境不能搜索外部参考：
- 优先使用用户提供、工程现有或本地可用参考；
- 关键准确性不足时使用可替换 Placeholder；
- 不把占位或 AI 猜测说成真实结构。

## 3｜来源优先级

官方 / 技术文档 / 真实实拍 / 品牌广告
→ 成熟商业动效 / 专业设计案例
→ 可信资产库
→ 社区案例
→ AI 概念参考。

准确主体优先真实素材，不让 Shape / JSX 为了省事重画复杂产品、人物、机械。

## 4｜参考决定实现路线

先选路线，再写 JSX / MCP：

- **Direct Asset**：直接导入 PNG / SVG / Lottie / Footage / 3D / Template；
- **AE Rebuild**：参考构图、节奏和运动规律，用 AE 原生能力重建；
- **Hybrid**：真实主体素材 + AE 信息层 / 控件 / 动效；
- **Placeholder First**：参考暂缺时先建立正确比例、裁切、Matte、动画和替换槽；
- **Generated Concept**：只用于不要求准确的概念元素，并保持可替换。

## 5｜最小 Reference Brief

复杂任务正式执行前只保留真正有用的 2–6 个参考：

`参考 → 约束什么 → 借鉴什么 → 不照搬什么`

Motion 重点任务至少明确：
- 主体 / 视觉依据；
- 运动 / 节奏依据；
- 哪些部分直接复用，哪些部分由 AE 重建。

Reference First 的目的不是增加流程，而是减少错误重建、无依据关键帧和后续返工。
