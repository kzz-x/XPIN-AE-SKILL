# Workflow｜New Project

用于从零创建完整 AE 镜头 / 工程。

## 1. Requirement
先确认：
- 文案 / 事实
- 视觉目标
- 画幅 / FPS / 时长
- 参考图角色：严格还原 / 风格 / 内容
- 最终需要可改什么
- 是否允许外部素材 / 3D / 插件

需求明确时不要长问卷。

## 2. Capability Preflight
判断：
- 哪些应使用真实素材；
- 哪些适合 AE 原生；
- 是否需要 2.5D / 真 3D；
- 是否需要外部模型；
- 是否需要插件；
- 哪些能力当前 MCP / JSX 不稳定；
- 缺失项如何占位。

## 3. Design Gate
对于 HIGH 风险新工程：
- 先给构图、动画流程、实现路线、素材 / 插件依赖；
- 用户没要求跳过时，先定视觉目标，再做工程。
用户明确说“直接做”时可以跳过。

## 4. Build
按模块化工程建立：
- 主合成
- 场景预合成
- 元素模块
- 控制
- 素材槽
- 辅助 / Guide
- 稳定 AI_ID

不要把所有东西堆在主合成。

## 5. Motion
- 动作按元素类型设计；
- 使用真正需要的 AE 能力；
- 错帧、缓动、重量、镜头节奏要合理；
- 不允许全场统一线性 / 同一 Ease。

## 6. Validation
检查工程、视觉、控制、动画、素材、兼容、AI 再编辑能力。

默认结束：
工程完成 → 关键帧 PNG → 用户自行 AE 预览。
不自动完整渲染。
