# Capability｜MOGRT / Essential Properties

## 原则
模板要“够用”，不是“能暴露的全暴露”。

适合暴露：
- 文字
- 主色
- Logo / 图片
- 尺寸
- 开关
- 少量动画参数

不建议暴露：
- 大量插件参数
- 复杂内部动画曲线
- 每个关键帧细节
- 只用于内部结构的工程参数

## Essential Properties
用于：
- 模块复用
- 不进入深层 Precomp 就能改关键内容
- 素材替换保留动画结构

## MOGRT
目标是在 PR 中修改“业务内容”，不是把 AE 整个工程暴露给 PR。

模板应保持：
- 性能合理
- 参数分组清楚
- 默认值可靠
- 缺字体 / 插件有说明
- 动画系统尽量封装在内部
